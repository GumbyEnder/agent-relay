# Everything can be dragged to the Idea Board

**Date:** 2026-11-20 · **Status:** decided

**Owner's words:** "Everything on this website has got to be movable to the whiteboard. That's
so poor that you can list it as a critical design principle."

**Decision:** anything a person can see as a thing can be dragged onto the Idea Board from
every page, shows the grabbing hand, and shows where it will land. A new kind of thing isn't
finished until it drags.

**In the code:** `application/x-beezilla-card` or `data-bz-card` payloads; the rule in
`docs/BEEZILLA-SCREEN-RULES.md`.
