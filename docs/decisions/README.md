# Decisions

Settled choices about BeeZilla and Dev Boards, so no agent re-argues them. One file per
decision, **named by its title** (no numbers: parallel sessions would collide on them).

Each file: the date, the owner's words exactly as they said them, the decision, what it
means for the code (with the guard test or check that enforces it, if any), and what it
superseded. To change a decision, write a new file that says which one it supersedes, and
mark the old one "Superseded by …" — never edit the old reasoning away.
