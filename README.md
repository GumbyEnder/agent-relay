# Agent Relay — Starter Package

## Contents
- docs/AGENT_RELAY.md — full product & engineering spec
- docs/PROTOCOL.md — five agent verbs
- docs/GROK_BUILD_PROMPT.md — paste into Grok Build to continue
- src/ — application source (board UI, store, seed)

## Use with Grok Build
1. Start a new Grok Build session.
2. Attach this zip or unpack and paste key files.
3. Use docs/GROK_BUILD_PROMPT.md as the instruction, and say what you want next.

## Local (if you have Node 22)
```bash
npm install
npm run dev
```

See docs/AGENT_RELAY.md for architecture, data model, and roadmap.
