Install BeeZilla on Windows

The desktop app is the same conversation as this site, running on your own machine. It keeps your work in a local database, talks to BeeZilla when it needs an account or a recipe, and updates itself when a new build ships. Windows 10 or 11, 64-bit.

The link is read from the release feed, so it always names the build the app itself would update to.

What you get

  • The full chat, voice and files, without a browser tab.
  • Your projects and documents stored locally in %APPDATA%\BeeZilla\data.
  • Connect a BeeZilla account, or paste your own provider key in Settings.
  • Updates download in the background and apply on restart.

Installing

  • Run the installer, choose a folder, then open BeeZilla.
  • Menu → Connect BeeZilla account… to sign in, or set a key in Settings.
  • No separate server to run: the app carries its own local runtime.
The build is not code-signed yet. Windows SmartScreen will warn the first time you run it — choose More info → Run anyway. Updates use the same GitHub release feed, so a new version is offered in the app rather than emailed to you.
